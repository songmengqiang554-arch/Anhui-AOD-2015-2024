# Verification and scientific interpretation boundaries

1. This preparation does not train RF/Ridge/HGB/XGBoost, rerun SHAP, or rerun a trend test. Its PASS status concerns existing targets, saved predictions, metric definitions, split identity and stored trend counts.
2. NDVI interpolation uses the full period and can use future months. Removing NDVI preserves all 40 yearly R2 signs and four negative LOYO means; it supports sensitivity of the stated transferability conclusion, not absence of preprocessing look-ahead.
3. Annual MK has ten annual means per grid. Ordinary seasonal MK and the covariance-adjusted seasonal sensitivity are distinct methods. Stored significant counts are 1325, 1341, and 1325, respectively, out of 1343. The equal annual/adjusted totals are different grid sets, with five exclusive grids on each side. The adjusted set contains 16 fewer grids than ordinary seasonal MK.
4. No successful official 3PW result is claimed. The historical 3PW attempts failed and are not replaced by a guessed implementation. Seasonal covariance adjustment is not complete removal of time dependence.
5. The fixed spatial region registry establishes original membership. Checking those labels is not a new proof that each region is geometrically connected or that no spatial dependence remains.
6. SHAP is model-based association, not a causal attribution. Saved residual Moran outputs diagnose remaining spatial structure.
7. Historical scripts retain legacy dependencies and output structures. They require explicit path/environment work for retraining; exact reproduction from raw provider archives has not been newly certified.
8. GitHub publication does not itself provide a data DOI. No repository URL, DOI, or public-release approval is fabricated by this local preparation.
